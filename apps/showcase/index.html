Four services. Clear authority.

Quotes and financial truth follow separate paths

Trading Core Java / Spring

Order validation and lifecycle, execution accounting, exact decimal P&L, persistence, reconciliation and transactional inbox/outbox delivery.

Realtime Gateway Go

Market-data normalization, authoritative bars, bounded quote fanout and order-update hints that trigger Core refetches.

Web Terminal Next.js / React

Per-symbol quote subscriptions, one imperative chart, explicit uncertainty and notifications grounded in Core state.

AI Insights Python

Validated asynchronous enrichment with durable worker state, bounded resources and deterministic public fixtures. No trading capability.

Engineering decisions

Authority before optimism
HTTP submission success is not a fill. UNKNOWN stays uncertain; ambiguous attempts preserve their idempotency key for deliberate retry.
Financial precision
Core calculates New York Day P&L from execution cash flow, commissions, fresh marks and persisted opening valuations. Missing evidence stays unavailable.
Delivery with recovery
Stable event identities, database transactions and Kafka transactions make replay safe within explicit service boundaries.
Security boundaries
Kafka mTLS and service ACLs, nonce CSP, exact browser origins, bounded admission and isolated containers complement dependency and image verification.
Evidence over claims
Unit, contract, real-infrastructure integration, browser and failure tests exercise behavior. Performance comparisons separate security overhead from optimization benefit.
